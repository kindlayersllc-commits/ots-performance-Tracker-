OTS PERFORMANCE — INSTALLABLE WEB APP

1) Upload this folder to a static HTTPS host (Netlify, GitHub Pages, or similar).
   The website must be served over HTTPS for installation/offline features.
2) Open the hosted URL in Safari on your iPhone.
3) Tap Share → Add to Home Screen → Add.
4) Launch OTS Performance from the new Home Screen icon.

Data is stored locally in the browser on that device. It is not synced or backed up.
This is a personal prototype, not an official Air Force app.
